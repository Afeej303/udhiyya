# Tasks

Each member edits only their own file: `M1.md`, `M2.md`, `M3.md`. This keeps the shared branch conflict-free.

## Status values
- **Backlog:** not started.
- **Ready:** requirements and dependencies are clear.
- **In progress:** being worked on.
- **Blocked:** state the blocker and who is needed. Send a `BLOCKED` ping.
- **Done:** acceptance criteria met, checks run, docs updated, with evidence.

Features (M3 only) also use: **Self-verified** (V0 and V1 passed), **Awaiting V2** (`READY` sent, queued, not a blocker), **Flag on** (V2 passed).

## Rules
1. One owner per task. Split tasks that cannot be finished and verified in one short session.
2. Record assumptions as `ASSUMED:` lines under the task.
3. Never mark Done without evidence.
4. MVP tasks outrank enhancement tasks.
5. The planner seeds these files at setup; owners then edit freely.
